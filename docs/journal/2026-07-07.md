# 2026-07-07 — Firefox provisioning

Added Firefox as a browser sibling to Chrome. `cask "firefox"` lands in the
Brewfile browser grouping; the app installs cleanly (152.0.4).

Hardening is a separate, later step because the daily-driver profile lives in
Firefox Sync and must exist locally before it can be hardened. The sequence is:
install, launch and sign into Sync, then run `scripts/configure/firefox.sh`.

`scripts/configure/firefox.sh` deploys `manifests/firefox/user.js` into the
active profile. Profile detection prefers `installs.ini`'s `Default=` (the
profile the browser actually launches) and falls back to the
`*.default-release` directory. It backs up any hand-written `user.js` to
`user.js.bak` once, and a matching copy is a no-op.

The `user.js` set is moderate and daily-driver-safe: telemetry, studies,
sponsored new-tab and address-bar content, and speculative network chatter off;
tracking protection and HTTPS-only on. Site-breaking prefs (resist
fingerprinting, cookie-clear-on-shutdown, first-party isolate) stay commented at
the bottom to opt into per machine. arkenfox is cited as the canonical reference.
