# 2026-06-03 — Discord: reversed Legcord for official app + Little Snitch

## What changed

Yesterday's Legcord choice was reversed. Discord now runs as the **official
desktop app, contained by Little Snitch**. Legcord was uninstalled and its
state wiped; `discord` and `little-snitch` casks installed and signature-verified.

## Why the reversal

Researching the trust case dismantled the premise the Legcord choice rested on:

- **Tencent is not the argument.** Minority passive investor, no board seat,
  Discord is a Delaware/SF company; Chinese data-compulsion law binds Tencent,
  not a US company through a minority stake. "Tencent reads your DMs" is myth.
- **A third-party client is a supply-chain downgrade.** Legcord is bus-factor-1
  (one maintainer's Apple cert + CI secrets, no reproducible builds, no audit)
  with a one-toggle on-ramp to arbitrary-code client mods. Discord's official
  app has a funded, audited, fast-patched supply chain. Swapping them trades a
  hardened custodian for a hobbyist one.
- **No client fixes the real complaints.** Age-verification ID collection, the
  Oct 2025 vendor breach that spilled ~70,000 government IDs, no E2E on DMs,
  retention, and law-enforcement disclosure are all server-side. Telemetry is
  identical on web and desktop. So the only thing a client switch buys is
  removing Discord's native binary, and the browser PWA does that better than
  any Electron wrapper.

The coherent move: keep the official app's supply chain, contain its local
invasiveness. Little Snitch blocks the telemetry at the network layer with
per-app per-domain wildcard rules (wildcards matter because Discord rotates
telemetry across shared CDNs). The browser PWA remains the stronger-containment
alternative; a Parallels VM ([ARCH-0016][16]) is the escalation if process
enumeration and filesystem reach need containing too.

The "dedicated user account" idea was rejected as a half-measure: macOS lets any
non-root process enumerate every user's processes, so it would not stop game
detection while only looking like isolation.

## Firewall choice

Verified Little Snitch is still best-in-class for per-app per-domain outbound
control on macOS 26 / Apple Silicon. LuLu (free, open-source) now ties on the
core capability and is the fallback, but its bulk-domain UI is cruder and it
lacks the wildcard edge. Get the perpetual full Little Snitch licence, not Mini.

## Little Snitch rule strategy

Two corrections drove a separate decision ([PROV-0013][p13]):

- **Silent Mode (Allow) only observes**, it logs connections in Network Monitor
  but does not create rules. Rules come from Alert Mode or hand-authoring.
- **Homebrew binaries report both the `/opt/homebrew/bin` symlink and the
  resolved `Cellar` versioned path** (verified with `ps` + `lsof`), so hand-path
  rules for brew tools risk breaking on `brew upgrade`.

Resulting split: **deny** via Little Snitch's built-in blocklist subscriptions
(AdAway, Peter Lowe, URLhaus, reputable publishers, auto-updating), big evolving
lists at the DNS layer; **allow** via Alert Mode for churny Homebrew tools and
GUI apps, plus a small hand-drafted stable-path baseline tracked at
`manifests/littlesnitch/dev-allow.lsrules` (git/curl/ssh to known source and
package hosts) for chezmoi deployment.
