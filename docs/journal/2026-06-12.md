# 2026-06-12 — Hide the OrbStack folder from Finder

## What changed

`scripts/configure/orbstack.sh` hides the `~/OrbStack` file-sharing mount from
Finder via `chflags hidden`.

OrbStack hardcodes `~/OrbStack` as its NFS view and does not support relocating
it ([orbstack#239][239]); the data itself already lives in
`~/Library/Group Containers/`, so only this zero-byte view sat visibly in the
home directory. The `UF_HIDDEN` flag survives remounts, so setting it once is
durable. The catch the script encodes: the flag can only be set while the
folder is a plain directory (OrbStack stopped) because a live NFS mount has
immutable flags; the script skips when the folder is absent, mounted, or
already hidden.

[239]: https://github.com/orbstack/orbstack/issues/239
