# 2026-07-21 — MacWhisper migration: real storage layout, curated settings

Migrated MacWhisper from the old machine over an SMB mount of its home
directory. The session rewrote the migration approach twice; capturing the
ground truth so the next machine is a one-step run.

## Storage layout (2026 builds)

- **Real home (non-sandboxed)**: `~/Library/Application Support/MacWhisper/`
  - `Database/` — `main.sqlite` (+ WAL) with sessions, transcripts, recorded
    meetings, tags, speakers; `ExternalMedia/` holds the meeting/imported
    audio and is the bulk of the bytes (2.6 GB here for 23 sessions).
  - `RecordedMeetings/` — empty scaffold on the source; nothing to move.
  - `models/` — downloaded models; re-downloadable, not migrated.
- **Decoy**: `~/Library/Containers/com.goodsnooze.MacWhisper/` — a stale
  sandboxed-era install. Its `Application Support/MacWhisper/Database` has an
  old schema (no `session` table) and no data. Migrating it looks successful
  and delivers an empty library. Never copy the container.
- **Model cache**: `~/Library/Caches/argmax-sdk-swift` (WhisperKit/Parakeet
  downloads, 2.9 GB) — pure cache, never migrated.
- **License + API keys**: macOS Keychain only; re-entered once per machine.
- **Prefs plist**: `~/Library/Preferences/com.goodsnooze.MacWhisper.plist`
  mixes user intent with machine state; the two largest entries are per-app
  dictation configs with embedded app-icon TIFFs (~110 KB each).

## Division of labor decided

- **Settings = config, deployed, not migrated.** A curated plist (66 of 93
  keys: prompts, dictation dictionary, custom export formats, AI-service
  metadata sans secrets, behavior toggles, migration markers; icon blobs
  stripped, window frames / device UUIDs / download state dropped) lives in
  the private dotfiles repo and applies via a chezmoi `run_onchange` script
  running `defaults import`. Personal vocabulary contains real names, hence
  the private repo, not this public one.
- **Data = migrated by `scripts/migrate/macwhisper.sh`** (rewritten today):
  rsync of `Database/` (with `--delete` and a dated backup of a non-empty
  destination) plus `RecordedMeetings/` when present.

## Verification caveat

Query the copied database with plain `mode=ro`. `immutable=1` ignores the
WAL, which can hold the app's last un-checkpointed deletions, so it
overcounts (source read 25 sessions immutable vs 23 real after WAL replay).
