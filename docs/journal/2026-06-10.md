# 2026-06-10 Zed provisioned: cask, manifest config, agent-panel lane

## What changed

Zed joins the editor roster with a reproducible config instead of a hand-tuned
one. Three pieces:

- **`cask "zed"`** in `manifests/Brewfile`, next to Cursor and VS Code. The
  cask links the bundled CLI as `zed`, so no in-app install step.
- **`manifests/zed/`** holds `settings.json` and `keymap.json`;
  `scripts/configure/zed.sh` copies them into `~/.config/zed/` with
  cmp-gated idempotence and dated `.bak` backups of divergent files.
  Copy, never symlink: Zed's in-app settings writes replace the file
  atomically and sever symlinks (zed-industries/zed#4469).
- **`docs/tldr/zed.md`** captures the config surface, paths, and the
  provenance of every setting.

## Why these settings

Zed is treated as the AI-first editor it is, configured around two AI lanes:

- **Agent panel**: Claude Code declared under `agent_servers` as a custom
  ACP agent (`npx -y @zed-industries/claude-code-acp`). Fully declarative,
  zero per-machine registry steps; auth and model choice stay with Claude
  Code itself. Node is already in the Brewfile.
- **Edit predictions**: Zeta, Zed's free open-source model, stays on as the
  default provider and activates after a one-time Zed sign-in. Inline
  predictions complement the agentic lane rather than competing with it.

The editing baseline came from research across official docs, Zed-dev
dotfiles, and community consensus: vim mode with relative line numbers and
no cursor blink, inlay hints on, telemetry off. Theme is Catppuccin
Mocha/Latte (system mode), the most-downloaded community theme.

Extensions install declaratively via `auto_install_extensions`, the only
headless path (no extension CLI exists). The set is matched to this
machine's actual stack: toml and make for the forge crates and Makefiles,
dockerfile and docker-compose for the container tier, sql, env, csv for
repo data files, lua for the nvim configs next door, basher for shell
scripts, git-firefly for git file syntax, markdown-oxide for PKM-style
markdown. Every id was verified against zed-industries/extensions before
landing in the manifest.

One formatting carve-out: Markdown `format_on_save: off`, since formatters
mangle the reference-style links this repo's docs depend on. The terminal
font is MesloLGS Nerd Font Mono, the same family string Ghostty uses.

The creator angle came up mostly empty: ThePrimeagen never left Neovim and
Theo published no config. The steal-worthy material was Thorsten Ball's
dotfiles and Syntax.fm episode 948.
