# zed-run

> Dispatch Zed tasks without reparsing selections or file paths through a shell.
> Zed provides file and selection context through `ZED_*` environment variables.

- Review the current Zed file in tuicr:

`zed-run tuicr-file`

- Open the current Zed file in Obsidian:

`zed-run obsidian`

- Recall brain notes for the current Zed selection:

`zed-run recall`

- Capture the current Zed selection into the brain:

`zed-run capture`
