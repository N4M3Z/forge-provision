# opencode

> Run the OpenCode terminal coding agent through the local shared wrapper.
> The wrapper adds session capture and read-only policy for automated reviews.
> More information: <https://opencode.ai/docs/>.

- Start an interactive session:

`opencode`

- Continue the latest session:

`opencode --continue`

- Run OpenCode through shared provider policy explicitly:

`sd agent run opencode {{arguments}}`
