# grok

> Run the Grok coding agent through the local proxy-aware wrapper.
> Interactive runs use workspace sandboxing and shared session capture.

- Start an interactive session:

`grok`

- Continue the latest session:

`grok --continue`

- Bypass the local AI proxy for one session:

`noproxy grok`

- Run Grok through shared provider policy explicitly:

`sd agent run grok {{arguments}}`
