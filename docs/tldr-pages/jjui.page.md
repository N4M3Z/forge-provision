# jjui

> Browse and edit a Jujutsu repository in a terminal interface.
> Run it from a repository that contains a `.jj` directory.
> More information: <https://github.com/idursun/jjui>.

- Open the current Jujutsu repository:

`jjui`

- Show available options:

`jjui --help`

- Show the installed version:

`jjui --version`
