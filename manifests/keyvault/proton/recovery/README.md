# Proton account recovery

- `recovery-phrase.txt` — the 12-word recovery phrase (digital copy)
- `recovery-phrase.md` — print template; fill in the words, print, store the paper in a sealed envelope separate from the other key backups
- `account-recovery.asc` — the recovery key export

Any one of these resets the Proton password and recovers full account access, so treat them as account-takeover material. Verify the phrase against Proton: Settings → Recovery → Recovery phrase.
